## B. Pipeline (▶ = prepRun)
Preflight: running → ignore; no sources → "add at least one source"; base-name clash → "!!! A and B are both inputs/<base> -- rename one" / status; save project; if a stop reached Describe last time → resetDescribe; then startPrep: startRun, log ">>> prepare: N input files" + each file + the inputs summary + context line; on completion: stopped → "stopped — finished work is kept"; error → "prepare FAILED: %v" / "prepare failed — see log"; success → ">>> prepare wrote:" + logOutputs(inputs, describe, transcript), "prepared — N files"; then refresh, gates, refreshCut; endRun unloads audio models.
Phases: ensureAudioModels first; separation 0..0.1 if asked; ingest to 0.3 (speech track 0.5, frames track 0.5); understand 0.3..1.0 (describe 1/2, transcript 2/2). A stop that reached describing arms a restart of describing.

### B.1 Voice separation (first)
Inputs: rows with the split wish. Outputs in <project>/stems/: <base>.split-novoice.wav|.mkv (rest) and <base>.split-voice.wav (voice), names keeping the original's timestamp. Skip when both exist (">>> [base] already split"). Work dir <base>.work removed on entry and on success only. Steps: decode to 44.1 kHz stereo pcm; chunk at 300 s on silences (seek 20 s); per chunk upload + audioRun(SepModel, {audio}); stems from named_audio_outputs (base64 wav): voice = vocals|voice; rest = instrumental or every other stem mixed with amix normalize=0; join parts; video → mux rest as mkv (video copied, flac); log ">>> [base] split into A and B" and a loudness report (mean volume of mix, voice, rest; lopsided warning when rest is ≥10 dB under the mix). sepApply: the row becomes two rows (rest keeps footage; voice takes the narrator tag); the wish is cleared; page updated, project saved.

### B.2 Per input: audio, ASR, alignment, diarization, segments → prepare/inputs/<base>/
1. voice16k.wav (skip if exists): ffmpeg -vn -ac 1 -ar 16000 pcm_s16le. Log ">>> [base] X s of audio".
2. Short take: dur < 2.0 s → ">>> [base] X s long -- a start/stop, not a take: written up as silence"; write transcript.txt "\n", words.json {"text":""}, turns.json []; merge; done. No server asked.
3. ASR (skip if words.json): ">>> [base] ASR (model)"; asrLong: chunk limit 60 s for qwen3-family models else 300 s; on "no room" errors halve down to 20 s (">>> !!! ASR: no room for that much audio (…) -- trying N s at a time"); chunks cut at silence midpoints (asrCuts: even pieces, seek capped at max/6 and step/3; silencedetect −35 dB / 0.4 s); scratch asr/ removed on success; per chunk upload + audioRun(ASRModel, {audio, language}); stitched {"text","words"} with start_sample/end_sample shifted; write transcript.txt, asrchunks.json, then words.json last. Empty text → ">>> [base] no speech found -- an empty transcript".
4. Alignment (only when an aligner is served and words.aligned.json absent): ">>> [base] aligning (model)"; task-addressed audioRun {audio, text, language}; pieces from the ASR's own chunks when word counts agree, else 60 s windows cut at silences (seek 4 s) with words shared by voiced seconds; each window trimmed to its sound (pad 0.25 s); halving on no-room down to 15 s; splitSpan at the quietest moment nearest the middle within [len/8, 7len/8]; reply words from words|alignment|segments|result.*, times from samples→ms→secs→plain (a bare start > 120 is samples); output {"words":[{word,start_sample,end_sample}]} written whole at the end; warning "!!! align: N s of the M s spoken has no word over it -- the times are wrong, and the cut will drop that footage" when bare ≥ 10 s and ≥ 8 %. Failure: warning if the ASR had word times ("the ASR's own times stand"); hard error if not.
   Aligner choice: settings id (whole list) else every task=="align" id with qwen3-aligner first; the first that answers is remembered for the run.
5. Diarization (skip if turns.json; failure fatal): window ladder 90 → 45 → 25 s on no-room; pass 1 scans windows with hop max(10, 2/3·win) for voices; anchor window = most distinct voices with ≥ 4 s speech (tie: the quietest best represented); anchor pieces per slot up to min(12, win/4) s skipping stretches < 0.3 s; hop = win − anchor − 1 (≥ 15 else "anchor too long"); pass 2 diarizes anchor+segment windows, resolves slots greedily by overlap ≥ 0.5 s one-to-one, unclaimed slots become extra speakers; same-speaker turns closer than 0.5 s merged; turns.json [{start_sample,end_sample,speaker_id "SPEAKER_NN"}]; log ">>> [base] N speaker(s), M turns (K slot(s) the anchor could not identify)".
6. Segments: words (end > start) from aligned or ASR times; guards ("N words carry no usable start_sample/end_sample -- the answer changed shape"; text but no times and no aligner → hard error naming the fix); speaker by greatest turn overlap, else nearest turn within 1 s, else SPEAKER_00 when there are no turns, else "?"; word end clamped to start+2 s; a segment breaks on speaker change, gap > 0.7 s, or length > 12 s; transcript.tsv "%.2f\t%.2f\t%s\t%s"; transcript.srt with [SPEAKER_NN] prefixes; log ">>> [base] N segments".
Audio server: audioURL = Settings > NAIVEPOST_TTS_URL > AUDIOCPP_SERVER > loopback; health check message "no audio.cpp server answering at URL -- start it (in the stack's compose folder: docker compose up -d audio), or point Settings at where one runs"; uploads via POST /v1/ui/upload (octet-stream, X-Audiocpp-Filename, content-length, optional bearer; 403 → --ui-management hint); tasks via POST /v1/tasks/run {"model","request"} with no client timeout; ensureAudioModels checks ASR (task asr), diarization (diar) and, when asked, separation (sep) with install hints for the shipped defaults.

### B.3 Frames → prepare/inputs/frames/<base>/
Marker .interval "<interval>|<scale>": match → only stampFrames (renaming legacy numbered frames) and ">>> [base] frames already extracted (Xs, scale), skipping". Else remove the folder; ">>> [base] extracting a frame every Xs at <scale>" or "…EVERY frame -- gigabytes"; filter fps=1/interval + scale (a take shorter than one interval: scale only, -frames:v 1); pattern f%06d.jpg -q:v 4; workers clamp(NumCPU/4, 2, 8), 1 when < 4 frames per worker or every-frame; total = round(dur/interval); chunks of whole intervals, a 1-frame tail folded into the previous; -progress pipe:1 parsed for out_time_us; every command logged as "    $ …"; then stampFrames renames f000001.jpg → <start+(n−1)·interval as YYYY-MM-DD_HH-MM-SS>.jpg (-1, -2 within one second); ">>> [base] N frames extracted".

### B.4 Describe → prepare/describe/<base>/events.tsv (+ state.txt, .llmframes/)
Per footage source: frames sorted by stamp; chunks of 4; frames scaled to 896 wide once into .llmframes unless the preset already is (896w or 480p). Resume: rows already in events.tsv are skipped by chunk start key "%.2f"; the last 3 rows seed the rolling window; state.txt seeds STATE ("Recording just started."). Other recordings' transcripts are shifted onto this video's clock (">>> [base] hearing X alongside it, starting N s in").
User message: context block; "STATE so far: …\nFrames cover t=As to t=Bs, X s apart."; "Just before this:" + "[+Ns] EVENT: …" ×3; the speech block with three always-present sections ("--- context before (do not describe) ---", "--- spoken during these frames ---", "--- context after (do not describe) ---"; "(none)" / "(no speech during these frames)"; lines "[+N.Ns] LABEL: text"); then per frame "[+N.Ns] FRAME i of n" + the image. Context segments: everything overlapping is during; before/after within 10 s, at most 2 per source.
Cache key = system + whole content (images inline); every success cached. Call llmChatRetry("describe", thinking off).
Reply: one "EVENT [+Ns]: …" per frame + "STATE: …"; fallback to a single EVENT/STATE; no label → "(no event line: …)". events.tsv one row per frame "t0+fs\tt0+fs+interval\ttext"; a frame with no stamped event within interval/2 is "same"; the first frame of a batch with no history is forced to "Calm; same view."; state.txt after every chunk; ">>> [base] event log complete (N chunks, M answered from the cache)". Readers fold "same" rows into the previous row. resetDescribe removes events.tsv/state.txt everywhere (">>> stopped last time — describing from the start again: …").

### B.5 Fix → prepare/transcript/
Outputs: <video>/transcript.fixed.tsv + subtitles.srt; <audio>/commentary.fixed.tsv; offsets.tsv (video, audio, offset; log ">>> offset: A starts N s into B"); session.tsv (gstart, gend, base, speaker|EVENT, text); session.txt (exactly the cut's brief text); retakes.tsv.
Blocks of 25 lines; per block: checkpoint, context ±5 s from every other source ("EVENT (base): …", "SPEAKER (base): …") and own events ("EVENT: …"); user = context block + "Context around these lines:\n…\nTranscript lines to clean (N lines, return exactly N):\n…"; up to 2 attempts, only attempt 0 uses the cache and only a valid reply is stored; validation: same count, start/end within 0.01, speaker identical; failure keeps the originals (">>> [base] block i/n failed validation, keeping original lines"). Merged timeline sorted by start; ">>> session timeline: N rows across M source(s)"; then findMarks; retake failures leave the timeline unmarked ("!!! retakes: … -- the timeline stands unmarked").

### B.6 Marking what was said twice
Gaming (retake prompt): spoken lines (< 4 → empty retakes.tsv) numbered with "(N.Ns pause)" lines at gaps ≥ 1.5 s and "--- the recording stops here; the next one begins ---" at source changes; stamps "mm:ss.t"; user = context block + "WHAT WAS SAID, line by line:"; 3 identical runs with the run index in the cache key, pooled and deduped; reply {"abandoned":[{from,to,again}]}; keepRetakes checks range, again inside the stretch, again beyond the timeline, reach ≤ 180 s; trimToRepeat against the words: marks shorter than 0.3 s of removal dropped; again=0 accepted only for a whole take; repeatFrom finds the earliest k where the tail is repeated (≥ 70 % run, skipping ≤ 3 words, fuzzy word match: equal, prefix ≥ 3 bytes, or one edit); rephrases trimmed to the broken-off tail (fragments ≤ 6 s); refused marks re-heard by a second ASR pass on both attempts; then placeEdges and mergeMarks; ceiling 40 % of speech ("!!! retakes: … called abandoned -- refused, nothing is marked"); retakes.tsv "S\tE\tAgain\tTo\tText"; empty file written on purpose.
Lecture (textedit prompt): words (< 4 → empty); seams = source changes (none → ">>> text edit: one recording, no seam to repair -- every word stands"); per seam: "JOIN k of n.\n\nBEFORE (the end of the take that was interrupted):\n<140 words>\n\nAFTER (the beginning of the take that follows):\n<140 words>\n\nAnswer {\"joined\":\"...\"} and nothing else: these N words and then these M words, in that order, with the stretch at the join left out."; thinking ON (measured: 15/29 → 20/29 joins right); reply matched back by tokens (keepMask walks backwards, preferring the later saying); the dropped stretch must be one stretch at the join (snap 3 words; other stretches ≤ 2 words are respellings); refusals logged "!!! text edit: join k: <reason> -- nothing removed there" (no words; not at the join; N separate stretches; stops N words short; starts N words past; > 40 words or > 60 % removed); cached only when usable; dedupeJoins (3 words either side, the earlier copy goes); marksFrom → placeEdges → mergeMarks; final.txt written with "|cut N|" / "|cut|" at every join; ">>> text edit: N of M words removed in K stretch(es)".
Edge placement: with word times the words fence both edges (start = after the last surviving word within 0.08 s, refined to the quietest moment within 0.4 s following the word's own sound ≤ 0.25 s; end = before the retake's first word); without word times the envelope alone (edgeReach 0.8 s, pad 0.05 s, late stamp 0.6 s). Envelope cache cache/edges, floor = 20th percentile of ±4 s raised to max(3×, +8); tail level = peak − 12 dB.

## C. LLM calls (prompt keys)
describe (thinking off, 4 frames, cached), fix ("transcript" step, thinking off, 25 lines, cached on validation), retake (thinking off, whole session ×3, cached per run), textedit (thinking ON, one seam, cached when usable). System prompt = the house rules cut to the job's sections + the job prompt (+ the context precedence rule when the context is non-empty). Retry policy: unusable answer → one 2 s retry; transport death → 5 s, 20 s, 1, 2, 4 min; a status code is never a transit failure.

## D. final.txt
Surviving words as written (folded spellings skipped), "|cut N|"/"|cut|" at joins. Hand edit (mtime after retakes.tsv) → marks remade with no model (">>> final.txt was edited after Prepare -- the marks are remade from it, no model asked"); words never said → "!!! text edit: N word(s) in the text were never said -- left out, there is no sound for them"; > 40 % removed → refused. Spelling pipeline: aligner tokens glued (leading space = pieces), dressed from transcript.txt (case/punctuation, look-ahead 8), then respelled from session.tsv's fixed lines (resync ≤ 6, whole respelling on the first word of a run, only .raw changes).

## F. Invariants
1. Every stage skips when its output exists; markers are written last and whole; scratch removed only on success; server documents are never rewritten.
2. Base names unique; srcClock is the only clock and gets the whole session; frames named from numbers; split halves keep the stamp; split products cannot be split again; the wish is spent by granting it.
3. Widgets are the GUI thread's; runners read caches.
4. ⏸ resumes; ⏹ restarts describing on the next ▶ only; transcripts and frames are never thrown away.
5. Cache keys contain the whole request; only usable answers are cached; fix is byte-identical or discarded; retake answers in line numbers; textedit can only delete; "prefer the later saying" is the direction of the match; marks are markings not deletions; empty retakes.tsv means asked and none.
6. No aligner is a working setup; no ASR word times and no aligner is a hard failure; diarization failure is fatal after the ladder; quietSpots is best effort; no speech is a real case everywhere; an empty key sends no auth header; unknown system-context headings go to every job.

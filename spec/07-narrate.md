# 07 — Narrate

An editable line per clip: what is said over it, in which voice, with what emotion. ▶ writes the lines and speaks them. Turn narration off and everything that exists to carry one is greyed.

- **Narration tick**: "Whether this video has a narration. Unticked, ▶ writes none, the lines already written are left alone, and Produce drops the game-volume slider…" Off greys the lines, the preview and the voice picker; Produce renders as if there were no lines.
- **Preview**: the finished frame (crop, zoom, stops, titles) with the narration mixed over the cut's sound; click = play/pause. Transport: back 3 s, ▶/⏸, forward 3 s, ＋ new line at this second, a slider over the cut's own clock ("what the edit removed is not on this bar…"; paused, the wheel steps a frame), the clock "session · cut/length", the shared volume.
- **Lines column**: one row per entry, sorted by clip then offset. Row: time entry (mm:ss.s on the session clock; typing moves within the clip; Enter/leave may move it to another clip; a time in a gap is refused and written back), status ("– end time", "(~)" while estimated, "(no line — this clip plays on its own audio)", "(caption — the viewer reads it; never spoken)", warnings "⚠ ~N s of speech, M s before the clip ends|the next line" and "⚠ this clip's lines run N s past it — the render will have them moved earlier[ and sped up]"), ▶ speak this line (audition from 3 s ahead where those seconds are its own, then carry on down the cut), ↻ re-roll (new take, same words), ＋ add a line below, 🗑 remove (the clip plays its own audio). The text box holds `[emotion] words` or `[top|center|bottom] words` for captions; the tooltip explains the tag, the judge vs weighted mixes, and the eight base emotions.
- **Voice picker**: Who speaks (No audio — captions only; Narrator 1..4 — the recording tagged on Prepare; every .wav in the voices folder), the take band's ＋ − ▶, "Add file…" (copy a recording into the voices folder). The **take band** (only for a narrator slot with a recording): the recording's waveform; drag to select, ＋ makes it a take (≥ 0.4 s), − takes seconds back out (splitting takes), click sets the red bar, ▶ plays the takes from the bar (or the raw recording when there are none), wheel zooms, Shift+wheel pans; "With no takes the seconds are chosen for you." Sample: an entry (default "This is the voice the narration will be spoken in. It should stay clear and easy to follow for a couple of minutes."), ▶ speak it, ⏹, ⟳ new take; pitch −6..+6 semitones ("Shift the reference recording before it is cloned — a different speaker, not the same one transposed"), applied 400 ms after the last move.
- Inputs: "N clip(s) · mm:ss[ · ⚠ N clip(s) unwritten, N line(s) off the cut][ · no timeline]"; "no cut yet — build one on the Cut step". Outputs: "narrate/ — narration.json, the voice reference and the synthesis cache".

## 2. Flows

### F4.1 ▶ Write and speak
S1 Refuse: busy; no cut ("no cut yet — build one on the Cut step first"); narration off ("this video has no narration — tick Narration at the top of this page to write one"); no session timeline ("run Transcript first — no session timeline"). S2 Pull half-typed rows; keep the previous file as `narration.prev.json`. S3 Save the project; job "narration" 1/2 (the writing owns the first half of the bar, clips counted as they stream), log ">>> narrate: <why> — writing N clip(s), one LLM call, then speaking them" where <why> is the staleness reason ("there is no narration yet" / "clip N has no narration — it is new, or the cut moved under it" / "the narration has lines for clips the cut no longer has") or "rewriting every line"; one model call (F4.2). S4 Replace every line (REVIEW: the prototype always rewrites; the Readme promised only missing lines — the rewrite SHOULD rewrite only clips with no entry unless the user asks for all, via a choice on the ▶ or the policy); the silent list is cleared; save; rebuild; ">>> narration written for N clips"; "narration written — speaking it". S5 Captions-only voice → done ("narrate: captions only — N line(s) written, none spoken"). S6 Job "speaking" 2/2, one task per line: checkpoint; skip blank text or a cached wav; else synthesize (F4.4). ">>> narrate: N line(s) spoken, M already in the cache". S7 Done: status "narration ready and spoken — ▶ the preview hears it in place" / "narration ready — captions only, nothing spoken" / "<stage> stopped" / "<stage> failed — see log". (Prototype bug: these are written to the progress bar's hidden text and never shown; they belong on the status line.)

### F4.2 The narration call
System = house rules + the "narrate" prompt (+ the speech addendum when the clips play what people said out loud: "THIS VIDEO PLAYS WHAT PEOPLE SAID OUT LOUD… never say one back: set it up before it lands, or react after it"; + the captions addendum for a captions-only voice: write for the eye, emotion "", every entry has a placement). User = User Context (+ the speech rule) + "THE CLIPS AND WHAT IS KNOWN ABOUT EACH:" + per clip "CLIP n: a–b (X s[ of footage at Rx, Y s on screen], at most W words -- fewer is better, none is fine)" with its lines within ±4 s as "[+Ns] LABEL: text" (the narrator's mic as NARRATOR; "(no lines over this clip: nothing said, nothing described)"), inserts described ("not footage: a graphic or clip inserted here … Narrate what is ON it, or say nothing"), and effects as "[+Ns] MARKED: name" / "[+Ns] CAPTION: text". Word ceiling per clip = clamp(0.75 · seconds, P.policy.narrationMinWords 8, P.policy.narrationMaxWords 30). Thinking on; web tools offered. **Tools**: `write_line(clip, at, text, emotion, pos?)`, `leave_silent(clip)`, `finish` (`02-services.md` §3.8). Validation in the tool: the clip must be one given; `at` clamped inside the clip and never its last second; `pos` normalised. Prototype: `{"entries":[{start,end,at,text,emotion}]}` matched to clips by echoed bounds within 0.5 s scanning forward, three attempts, thinking turned off after a call that wrote nothing. Streaming progress = written clips / clips. Not served from the reply cache (the TTS cache is the cache).

### F4.3 Fit a line to its clip (the render's rule, mirrored by the row warnings)
Lines pack in order from max(P.policy.narrationLead 0.3, at), never before the previous line's end + P.policy.narrationGap (0.3); need = packed end + P.policy.narrationTail (0.2). Over the clip: grow the clip by up to P.policy.narrationMaxExtend (4 s), never past the footage; still over: slide every line earlier down to the lead; still over: speed the speech up to P.policy.narrationMaxTempo (1.25×). Each is logged ("clip N: the narration does not fit where it was placed — moved X s earlier" / "clip N: narration X s does not fit Y s — sped up Zx"). Speech length = the wav's duration when it exists, else characters / the narration's own measured rate (default 15 chars/s, clamped 8..28).

### F4.4 Speak a line (TTS)
S1 Reference on disk (F4.6). S2 Audio server health; the TTS model served and able to clone. S3 Upload the reference (every line; a server path dies with a restart). S4 POST /v1/audio/speech `{model, input: text, voice_ref: <server path>, language: "en", options: {emotion_alpha "0.85", seed, and either emotion_vector "<8 floats>" with emotion_alpha "1" (a weighted tag whose names are all known) or use_emotion_text "true" + emotion_text "<names>" (the judge)}}`. REVIEW: the language is hard-coded "en" in the prototype; it SHOULD follow the project language or a policy field. S5 A reply under 1000 bytes or non-200 is a failure; else write `narrate/tts/<hash>.wav`. S6 Emotion vocabulary: eight bases (happy, angry, sad, afraid, disgusted, melancholic, surprised, calm) with kin words, 21 named blends as recipes over the bases; weights 0..1; unknown names go to the judge as words; never an error.

### F4.5 Preview the cut with narration
S1 Click the picture or ▶: play from the line (or from the cut's start; "nothing to preview yet — cut some clips first"). S2 The tick follows the picture; gaps are skipped forward (past the last clip → pause); a clip boundary is held while a line still speaks, up to 4 s; entering a line starts its wav at the offset the picture is at; a line with no wav pauses the picture, synthesizes it ("synthesizing line N" / "line N ready") and resumes at the line's start; a failed line is sticky per wav until its ▶ retries ("line N failed to synthesize — see log; its ▶ retries"). S3 Sound equals the render's: the whole clip is ducked by the game volume while a line speaks; lanes and hushes follow the cut; speed effects apply at seeks. S4 Seeks snap to the cut (a target in a gap lands on the previous clip's end going back, the next clip's start going forward). S5 Row selection while playing follows the playhead; selecting a row seeks to its line's lead-in (3 s ahead unless the previous line still speaks there). S6 ⏹ stops both players and hands ▶ back to the step.

### F4.6 Choose the voice and build the reference
S1 Pick a voice: captions only (nothing spoken); Narrator N (the recording tagged on Prepare; "narrator N is not tagged on the Prepare step — tag a recording, or pick another voice"); a file from the voices folder ("voice X is no longer in DIR — pick another"). Switching voices keeps what was already synthesized (the cache key carries the voice). S2 Reference: hand-picked takes win outright (no cap, no diarization needed); else automatic picks from diarization turns and the transcript: takes ≥ P.policy.refMinTakeSeconds (5) at least 2 s from other speakers with ≥ 1.5 words/s, up to P.policy.refWantSeconds (14) from at most 3 pieces; errors "nothing is tagged as narrator N on the Prepare step", "no diarization for X -- run Prepare, or pick the seconds by hand under the video", "no clean solo stretch found for the voice reference". S3 Level to −16 LUFS / −1.5 dBTP / LRA 7, mono 48 kHz pcm → `voice_ref_base.wav`; pitch-shift (rubberband, formants preserved) → `voice_ref.wav`. A reference whose wav header the server cannot read (extensible format, > 48 kHz) is re-cut. S4 Takes: ＋ on a selection ≥ 0.4 s ("take added: a–b"; "that is X s — a take has to be at least 0.4 s"), − subtracts seconds (splitting takes), ▶ walks the takes from the red bar; takes are sorted, merged when touching; changing takes, pitch or voice removes the shifted reference (and the base where needed). S5 Sample: speak the entry text in the voice (cached per voice and text; "sample in <voice>"; ⟳ = a new take).

### F4.7 Edit lines
- **Add at the playhead** (＋ beside the slider): between clips → "the playhead is between clips — the cut has nothing to narrate here"; within 1 s of an existing line → jump to it; inside a speaking line → "a line is speaking here until m:ss — add after it".
- **Add below** (＋ on a row): after the previous audio ends + 0.5 s ("no room after this line — the clip ends first").
- **Move** (time field): to another clip adopts its bounds; a gap is refused; never in the clip's last second.
- **Delete**: the row goes; the clip is remembered as deliberately silent ("line removed — the clip at m:ss plays its own audio").
- **Re-roll**: roll + 1, a new take spoken; the old wav stays.
- **Text**: `[tag] words`; a placement tag clears the emotion; emptying a box keeps the old emotion; autosaved 400 ms after typing; flushed on tab leave, window close and before Produce reads the file.
- **Refit** on entering the tab: lines keep their place against the video when the cut moved ("the cut moved — N line(s) followed their clips[, N sit on video the cut no longer has]").

### F4.8 Narration off
Greys the page; leaves `narration.json` alone; Produce hides the game-volume slider and renders without lines; the chain skips Narrate.

## 3. Data
`narrate/narration.json` (`01-project-and-files.md` §4); `narration.prev.json`; `voice.txt`, `pitch.txt`, `takes.json`, `voice_ref_base.wav`, `voice_ref.wav`, `tts/*.wav`, `samples/*.wav`.

## 4. Parameters used
P.policy: narrationMinWords, narrationMaxWords, narrationWordsPerSecond (0.75), narrationLead, narrationGap, narrationTail, narrationMaxExtend, narrationMaxTempo, narrationContextWindow (±4 s), ttsLanguage, refMinTakeSeconds, refPadSeconds (2), refWantSeconds, refTakeMax (3), refMinWordsPerSecond (1.5), takeMinSeconds (0.4), emotionAlpha (0.85), runInSeconds (3), speech rate defaults (15, 8..28). Engineering: tick 100 ms, seek debounce 120 ms, autosave 400 ms, band geometry, cache key format (frozen).

## 5. Rules
Entries always sorted; a line's clip bounds are the cut's numbers; `at` never in the last second; empty text is a deliberate answer; the preview plays the cut and equals the render's sound; a boundary is held while a line speaks; a hold resumes at the line's start; failed synthesis is sticky until retried; captions-only short-circuits everything that speaks; the run bar is the preview's transport only once the preview started; cache keys are stable and nothing deletes old wavs; hand-picked takes are never re-ranked; a voice not on offer leaves the picker empty rather than pointing at the wrong speaker.

## 6. Details confirmed against the code (verification pass)
- **F4.1**: the previous file is copied aside only once a valid narration came back ("    the narration it replaced is kept at <path>"); the silent list is cleared with the replacement; a captions-only voice still opens and closes the "speaking 2/2" job so the bar finishes.
- **F4.2 validation**: every clip must be answered for — a skipped clip ("clip N (a-b) got no entry") or a reply where no clip got a line ("every clip came back with no line at all") is refused; entries are matched forward only ("an entry says X-Y, which matches no clip (or is out of order)"); several entries on one clip are sorted by offset. With tools these are `finish`'s answers.
- **Inputs tooltip**: names `cut/cut.json` (clips, minutes), the staleness sentence + "— ▶ writes the narration again", `prepare/transcript/session.tsv` with its line count and the ±4 s rule, the session context verbatim, and "Spoken by <voice> at ±X.X semitones (narrate/voice_ref.wav)". A clip is "unwritten" when no entry sits on it and it is not deliberately silent; a line is "off the cut" when it sits on video the cut no longer has.
- **Re-roll / sample refusals**: "clip N has no line to re-roll"; "no audio is chosen — a caption has no take to re-roll"; "line N: new take, speaking it"; "pick a voice first"; "no audio is chosen — there is no voice to sample"; "type a sample sentence to hear the voice"; "still synthesizing the last sample…"; "sample playing" / "sample paused — ▶ resumes, ⏹ starts over" / "sample stopped". Each sample logs ">>> sample[ take N]: <voice> at ±X semitones — \"text\"" then "    sample: <file> (N kB, spoken in T | spoken earlier)"; an under-sized answer "!!! sample: <file> is N bytes — no audio came back".
- **Reference build**: logged ">>> voice reference built: X s, N words | N hand-picked take(s) from <base>". Automatic ranking: the speaker holding the most turn time; solo turns (nobody else within refPadSeconds), narrowed to the words inside them, ranked by words said with length as tie-break; takes under refMinWordsPerSecond dropped unless that leaves none.
- **"Add file…"** converts the recording to mono PCM wav in the voices folder under a sanitised base name, never overwriting (`name-2`, `name-3` …): the file name is the voice id every project's cache keys carry.
- **Take band messages**: "drag across the wave first — ＋ makes the selection a take"; "drag across the takes you want gone — － removes those seconds"; "nothing is picked in those seconds"; "no takes left — the seconds are chosen for you again on the next line spoken"; "no takes yet — drag across the wave and press ＋"; "playing the recording from m:ss — nothing is picked after it"; "playing N take(s), X s from m:ss"; "takes played" / "stopped playing the takes"; commit status "<what> — N take(s), X s of reference (14 s is plenty). Re-cut on the next line spoken." `takes.json` is keyed by recording base name, not slot, so re-tagging never moves somebody's takes; changing takes removes the built reference.
- **Preview**: a gap is held only while the speaking line is within its clip's end plus narrationMaxExtend; past the last clip both players pause; when the picture stops the narration stops too, except a line auditioned from its own ▶ over a clip with no footage, which speaks against a still frame.
